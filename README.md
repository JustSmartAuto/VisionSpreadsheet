# 直线卡尺

基于 **C# WinForms + OpenCvSharp** 的机器视觉卡尺示例。当前代码的核心功能是在灰度图上布置两组直线卡尺，分别检测并拟合两条直线，计算其交点坐标及第一条直线的角度，同时在图像上叠加显示有效点、剔除点和拟合结果。

## 功能概览

- 双直线卡尺的创建、拖动和参数调整
- 卡尺数量、长度、宽度、滤波尺寸及边缘阈值配置
- 从内向外 / 从外向内搜索，由暗到明 / 由明到暗 / 全部极性选择
- 一维灰度投影、差分滤波和边缘峰值提取
- 直线拟合、异常点剔除，以及两直线交点和角度计算
- 图像缩放、平移、适应窗口、原始尺寸显示和像素信息查看
- 工程参数的 `.prj` 文件读写

主窗口还保留了模板匹配、圆卡尺、矩形卡尺、棋盘格标定、畸变矫正和卡尺测距等界面；当前 `Form1.cs` 中实际实现的交互逻辑主要集中于**交线卡尺**。

## 环境要求

- Windows 10/11
- Visual Studio 2019 或更新版本
- .NET Framework 4.7.2 Developer Pack
- x64 运行环境（随项目提供的原生 OpenCV 4.6.0 DLL 位于 `bin/x64/Debug`）

项目采用传统 `.NET Framework` 工程格式，不是 .NET 8 / WPF 项目，也没有使用 NuGet `packages.config` 或 SDK 风格依赖还原。

## 构建与运行

1. 使用 Visual Studio 打开 `OpencvDemo-11-15/OpencvDemo-10-22/OpencvDemo.sln`。
2. 将解决方案配置设为 **Debug**，平台设为 **x64**。
3. 生成解决方案，然后启动 `OpencvDemo`。
4. 也可以直接运行已有的 `OpencvDemo-11-15/OpencvDemo-10-22/bin/x64/Debug/OpencvDemo.exe`。

若提示找不到 OpenCV 原生库，请确认 `OpenCvSharpExtern.dll`、`opencv_world460.dll` 和 `opencv_videoio_ffmpeg460_64.dll` 与程序位于同一输出目录。

单独编译 `Diaplay.sln` 前，需要先修正 `Diaplay.csproj` 中 OpenCvSharp 的历史相对引用路径；日常运行示例程序无需执行这一步。

## 直线卡尺使用步骤

1. 切换到 **交线卡尺** 页。
2. 点击打开图像，选择 BMP 或 PNG 图片；程序会按灰度图读取。
3. 点击添加直线卡尺，画面中会生成两组默认互相交叉的卡尺。
4. 拖动卡尺的起点、终点和区域，使卡尺覆盖待检测边缘，并分别调整两组参数。
5. 点击查找交点。绿色点表示参与拟合的点，红色点表示被剔除的异常点，绿色直线为拟合结果。
6. 在查找结果中查看交点 X、Y 坐标和直线角度。

图像区域支持滚轮缩放、左键拖动平移和双击适应窗口；右键菜单提供适应、原始尺寸、全窗口显示和另存为 BMP。

### 主要参数

| 参数 | 作用 |
| --- | --- |
| 卡尺数量 | 沿目标直线分布的采样卡尺数量 |
| 卡尺长度 | 垂直于目标边缘方向的搜索长度 |
| 卡尺宽度 | 用于灰度平均投影的区域宽度 |
| 滤波尺寸 | 一维差分滤波的核尺寸参数 |
| 阈值 | 边缘峰值筛选阈值 |
| 剔除点数 | 拟合前需要排除的异常点数量 |
| 最大误差 | 拟合流程保留的误差参数 |
| 搜索方向 | 从内向外或从外向内读取采样区域 |
| 边缘极性 | 选择由暗到明、由明到暗或全部边缘 |

## 实现说明

`Form1.FindLine` 对每个采样位置构造旋转 ROI，执行双线性采样和行方向平均投影，再利用差分卷积提取灰度边缘。检测到的边缘点经过直线拟合和异常点剔除后，以 `Ax + By + C = 0` 表示直线；两条直线均成功拟合后计算交点。

部分历史源码使用 **GB2312/GBK** 编码。修改 `Form1.cs`、`ToolBox.cs` 或部分卡尺图形源码时，应保留原编码，避免中文枚举名和界面文字乱码。
